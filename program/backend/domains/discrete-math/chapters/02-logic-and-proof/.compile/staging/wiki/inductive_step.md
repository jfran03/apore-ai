# Inductive Step in Mathematical Induction

The inductive step is the second step in a proof by mathematical induction. It shows that if the statement is true for one case, it is true for the next case. For example, in the statement 'the sum of the first n positive integers equals n(n+1)/2', the inductive step would be to show that if the statement is true for n, it is true for n+1.
