# Chapter sources

Drop your raw teaching material here before running stub compile:

- PDF, HTML, Markdown, or plain text
- Syllabus exports (`.md` or `.txt`)

Files in this folder are gitignored when the chapter lives under `program/domains/`.

After upload, run **Stub compile** from Setup (or `python scripts/stub_compile_chapter.py`) to generate `concept-graph.json` and `wiki/` pages.
